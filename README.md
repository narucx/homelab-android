# Homelab Control - releases

Android APK builds of Homelab Control, a dashboard and control app for self-hosted services
(Proxmox, PBS, the *arr stack, Jellyfin, Uptime Kuma and more). This repository holds release
builds only.

- Latest APK: https://github.com/narucx/homelab-android/releases/latest/download/homelab.apk
- Update feed used by the in-app updater: https://github.com/narucx/homelab-android/releases/latest/download/latest.json

Every release is signed with the same key, so Android only installs updates that come from the
original signer.
